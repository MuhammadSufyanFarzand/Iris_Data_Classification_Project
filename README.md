# 🌸 Iris Data Classification Using Machine Learning

This project demonstrates a supervised machine learning classification model using the famous Iris dataset. The model is trained to classify Iris flowers into three different species based on their sepal and petal measurements.

## 📌 Features

- Load and explore the Iris dataset
- Perform data preprocessing and analysis
- Split the dataset into training and testing sets
- Train a machine learning classification model
- Predict Iris flower species
- Evaluate model performance using classification metrics
- Visualize data distributions

## 🛠️ Technologies Used

- Python
- Pandas
- NumPy
- Matplotlib
- Scikit-learn

## 📂 Project Structure

```
Iris-Data-Classification/
│── iris_classification.ipynb
│── README.md
```

## 📊 Dataset

The project uses the built-in **Iris Dataset** from Scikit-learn, which contains **150 flower samples** from three species:

- Iris Setosa
- Iris Versicolor
- Iris Virginica

Each sample includes four features:

- Sepal Length
- Sepal Width
- Petal Length
- Petal Width
